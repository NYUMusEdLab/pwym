Tinkamo / TinkaMOD

TinkaMOD is a rapid prototyping environment for building interactive controllers and instruments with Tinkamo and JavaScript, all running directly in the browser thanks to recent Chrome Bluetooth support.

Historical documentation: compatibility with current hardware and Bluetooth browsers has not been verified.
