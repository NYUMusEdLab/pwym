# Melody & Context — non-commercial public edition

425 licensed melodic records:389 Bach soprano lines from the distinct Alberda/Hentschel edition,24 Winterreise vocal lines and12 Mozart Symphony39–41 ViolinI reductions. See ATTRIBUTION.md for licence, sources and changes. No Shanghai or earlier music21 Bach data bundled. The separately licensed389-setting Bach corpus uses ms3 TSV extraction; source MusicXML/MEI conversion warnings remain applicable and no commercial recordings are included. Local index import reads user-selected JSON in memory and does not upload.

No application analytics, cookies, storage, accounts, tracking or telemetry. Hosting infrastructure may keep standard access logs outside this application.

Static HTML/CSS/ES modules and JSON; no build/runtime dependencies or third-party script requests. Contour search is approximate and rhythm-independent; playback is synthetic selected-line audio. Staff cards are not a full MusicXML/MEI viewer; corpus timing, OMR and reductions require human review for research claims.
