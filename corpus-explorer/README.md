# Melody & Context — non-commercial public edition

425 licensed melodic records:389 Bach soprano lines from the distinct Alberda/Hentschel edition,24 Winterreise vocal lines and12 Mozart Symphony39–41 ViolinI reductions. See ATTRIBUTION.md for licence, sources and changes. No Shanghai, Shaanxi or earlier music21 Bach data bundled. Users may load all 831 Shanghai and 1,309 Shaanxi scores, or 24-score previews, directly from the publisher for authorized exploration. Score files are not proxied or hosted by this app. Full loads use a bounded browser queue, pause/resume and optional local storage. Partial indexes are labeled and can be resumed. The original publisher score ZIPs for Shanghai and Shaanxi can be selected and searched directly in the browser for authorized use, with local parsing and no uploads. The importer fetches corresponding version-pinned publisher metadata only when requested and no local JSONL files are selected. Browser support for deflate-raw ZIP entries is required; the local Python-to-JSON route remains available. The separately licensed389-setting Bach corpus uses ms3 TSV extraction; source MusicXML/MEI conversion warnings remain applicable and no commercial recordings are included. Local index import reads user-selected JSON in memory and does not upload.

No application analytics, cookies, accounts, tracking or telemetry. Optional browser storage retains only loaded full-collection indexes and the local preference. Hosting infrastructure may keep standard access logs outside this application.

Static HTML/CSS/ES modules and JSON; no build/runtime dependencies or third-party script requests. Contour search is approximate and rhythm-independent, with a selectable range of 4–32 notes per matched passage; playback is synthetic selected-line audio. Staff cards are not a full MusicXML/MEI viewer; corpus timing, OMR and reductions require human review for research claims.
