What has been tested

Browser checks cover generated audio playback, annotation persistence, and generated webcam video behind the drawing at 50% opacity. Shared drawing-input regression tests pass. Tablet portrait, landscape and split-view layouts were checked, including saved strokes after reload. All 234 published files across the three variants match the tested build (13 October 2026, source revision 228ff643).

Availability and limits

Full historical sessions have not been recovered. Webcam video stays in the current tab behind the graffiti; it is not saved or shared with annotations. Recording uploads are unavailable. Drawing input supports mouse, touch and pen, but actual iPads, Apple Pencils and physical cameras remain untested. Original catalog metadata and media endpoints respond; playback tests used generated tones, not original songs.

Recovered default drawings

The recovered “What a Wonderful World” set contains 18 drawing/background records and is preserved exactly as found. New entries into that song can begin with these drawings; the Songs menu can open a separate recovered copy. Existing saved annotations are preserved. The set may include later edits; original authorship and an untouched original state have not been established.

Project context

This is a variant of the Fresh Annotator family. Catalog identity is supported by the original application settings and the existing public catalog. An original release date has not been established. The restored version links to existing content; no music or participant records are included in this profile.
