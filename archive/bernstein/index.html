Historical study prototype · 2017 source

Bernstein Young People’s Concerts

A study interface for selected Leonard Bernstein Young People’s Concerts, bringing together video, captions, chapter navigation, transcripts and scripts.

Project record

The interface was designed to help users study the relationship between Bernstein’s prepared script and televised delivery. Users can follow captions or musical cues, click transcript passages or chapter entries to move through a concert, and consult the original script alongside the video.

The surviving repository contains ten episode pages, caption and navigation tracks, script PDFs and an Able Player implementation. The latest recorded source revision is dated 21 October 2017.

The original README records unfinished work on search, seeking, script display and volume controls. The protected study version fixes the seek-bar range and adapts the layout to smaller screens.

Availability

Open the protected study interface → A shared study username and password are required. Use Safari or Chrome; the embedded browser may not retain the sign-in prompt.

Episode 1 playback, pause, seeking, transcript links and chapter navigation were checked in Safari on 15 October 2026. Layout checks cover all ten episodes at desktop, tablet and phone sizes. The original search box remains unfinished; use the player’s Show transcript control, select Transcript, and use your browser’s Find command to locate words. The PDF is a separate script view. Other episodes’ full playback and physical mobile devices remain untested.

The original notice limits the site to study use and prohibits recirculation. It credits the concert video to The Leonard Bernstein Office Inc., courtesy of Kultur Video. Direct anonymous access to the hosted recordings is blocked; source history and project documentation remain public.
