MusEDLab / Project history

MusEDBox

A local Wi-Fi network for playful music tools.

Bringing the tools into the room

MusEDBox brought MusEDLab’s browser-based tools into New York City school buildings where Wi-Fi was not strong enough to support the work reliably. A Raspberry Pi served the tools over its own local Wi-Fi network, making access less dependent on the building’s connection.

Alex Ruthmann recalls that musedbox.musedlab.org distributed the software used on these Raspberry Pi boxes. This record preserves that purpose and the surviving technical documentation.

A small server for a shared musical space

The retained project documentation describes a Raspberry Pi 2, a MicroSD card and a USB Wi-Fi adapter. A prepared system image supplied the local server. The documentation also describes a local database and an optional connection to another Wi-Fi network for updates.

The software image was built and distributed through the lab’s Buildbot automation. The classroom experience ran on the local box; the build server’s role was preparing and distributing the software.

What survives

  • Project source and installation documentation identifying version 0.3.0.
  • A preserved source checkpoint dated 19 June 2016.
  • Alex Ruthmann’s account of the use of local Wi-Fi in NYC schools, recorded in October 2026.

The 2016 source checkpoint is evidence of the software’s history, not a confirmed first deployment date. The exact classroom tool bundle and a working restoration of a complete system image have not yet been verified.
