I use 'My Piano' ( [external link withheld] [link withheld] ) all the time to play around with melodies, get note references and do vocal exercises. It's also nice to play around with the sample sounds, record your own samples and it can be used to control midi software on a computer (even though the setup is more on the advanced user side).

To tune my guitar I like 'gStrings' ( [external link withheld] [link withheld] ) which is a pretty good chromatic tuner.

'Chord Reader' ( [external link withheld] [link withheld] ) is excellent for practing and learning new songs. It searches for song chords and displays them on an easy to read format on your phone or tablet. You can also save songs for offline use.
