Fresh AnnotatorSongs, drawings & annotation

Restoration preview: drawings + webcam

A multimedia annotation tool developed for Fresh Ed, connecting hip-hop educational content with drawings, text, audio and video contributions. The project supports culturally responsive learning and student songwriting.

Project date not established in the cited site record.

The restoration supports listening, text and drawing annotations, copies and URL sharing. Five Fresh song sets include recovered default drawings; Wonderful World has a recovered set in its own variant. Webcam video appears behind graffiti at 50% opacity and stays in the tab. Tablet-sized drawing layouts and browser input tests pass; physical iPads, Apple Pencils and cameras remain untested. Recording uploads, general import/export and full historical-session recovery are unavailable. Original music playback has not been fully retested.

Virtual Piano Duet v2Active project · piano duet & Melody Notebook

Active project + source

Improvise a virtual duet with pianist Steve Wogaman of the Chamber Music Society of Detroit. The public repository credits code adapted from Yotam Mann, design by Diana Castro and Alex Ruthmann, and code updates by Guergana Tzatchkova.

Responsive design update: May 2020, according to the public source README.

V2 tracks melodies as piano rolls, saves named phrases in this browser, and supports replay and compatible melody JSON export/import. No cloud sync or microphone recording. Browser tests cover capture, save/reload, replay and Makey Makey keys; physical hardware remains untested.

About this archive · availability, dates & sources

These records collect public documentation, existing images and available links from past projects. An archived project may still have a working app. Availability labels describe what is accessible, without promising full restoration.

Archive link review: 13 October 2026. A responding endpoint does not confirm playback, saving or every external dependency.

Dates appear only where supported by linked documentation; a missing date means it has not been verified. Existing project pages preserve further credits, research and context. Public source and curriculum are linked where their relationship to a project is established.

Private participant records and restricted media are not part of this public collection. Linked services retain their own access requirements. Historical links and third-party content may change.
