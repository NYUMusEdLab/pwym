Groove Pizza

Rhythm through keys, speech and sound.

A research prototype exploring drum programming for people with limited or no vision, with a circular rhythm view and alternatives to visual feedback.

Start with the keyboard

Open the prototype on a computer with a keyboard. Tab moves between the instructions, tempo and slice controls. With the instructions focused, use the left and right arrows to move through the directions.

The project recommends Chrome. Read its on-screen instructions for the full key mappings and audio modes.

Read the prototype instructions and source ↗

More than a visual grid

  • Keyboard controls: work with the rhythm and choose between key mappings.
  • Built-in speech: Practice mode gives spoken feedback while the music plays more quietly.
  • Sonification: another mode replaces most speech with tones; Performance mode switches off non-musical cues.
  • Color palettes: alternate palettes provide different visual presentations.

This prototype uses its own speech cues. External screen-reader compatibility has not been validated in this website review.
