      What has been reconstructed?

      This study recreates the alternating play/listen interaction, paired piano rolls, phrase threshold, musical memory, output controls and chunk-based composition documented by Khatchatourov and Pachet. The new layout preserves those working areas, not the original Java window chrome.

      • Impro: live keyboard/MIDI note input, interruption, learned phrases, continuation, pitch-constrained variation and answer, echo, no-response learning, rhythm/dynamics controls and replay.
      • Compo: a separate memory snapshot, statement/original/continuation/answer/variation/conclusion, repeat, rest, backtrack, per-chunk copy/delete and an exportable action trace.
      • Engine: official modern Continuator implementation at ec17dfd, MIT licensed. This is not the historical MIROR engine. Generated endpoints follow the manual’s pitch rules, but the historical internal-note exclusions, viewpoint provenance highlights, harmony rectifier, notation, audio/MIDI export, participant server and full settings are not reproduced. No claim of identical outputs or research equivalence.
      • Privacy: no names, participant account, microphone recording, analytics or server session upload. JSON exports include played notes and action times. They stay local unless you share them.

      MIROR-Body: documented, not simulated here

      The historical movement module used camera/sensor processing and movement-to-music mappings. This build does not imitate it with arbitrary mouse movement or claim Kinect compatibility. Its reconstruction needs source, mappings and sensor evidence.
