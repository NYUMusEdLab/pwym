Reconstruction and fidelity

Sousa and shared controls update

The Sousa header offers the recovered A-flat major and pentatonic adaptations, using twelve original MIDI arrangements and two original movies. The source's 130-beat loop, 1.1 tempo multiplier and literal pitch sets are retained; MIDI beyond the loop is preserved but not played. The major-labelled pitch set contains D natural. Archived Electric Bass34 and Flute74 substitute for the original system bass33 and piccolo72.

The prepared WebSocket relay shares selected instrument presence and changed parameter values, with no exclusive control locks. Audio, images, scene choice, playback and recordings remain local. It automatically joins on a configured authenticated host and restores changed controls on reconnect. No server is deployed: source repository DNS and shared-room hosting support remain blockers. Twenty-nine automated checks pass; live WebSocket and current browser/audio testing remain unverified.

This private browser build reconstructs Jam2Jam AV 1.1c, standard JamSkolan and AV Visualize from recovered source, MIDI, artwork, movies and soundfonts. The native applications have not been run for direct comparison.

Original materials and behavior

Twelve scene profiles preserve each version’s loop lengths, tempos, pitch and articulation rules. Density selects the authored light, medium or full arrangements. Visualize preserves the two-accepted-value 0.03 filter and activity counters. The archive example has 3,477 movements and 601 accepted points. Its raw instrument IDs and out-of-range values are retained.

Browser adaptations

Web Audio synthesis, envelopes, filters, audio effects and microphone processing approximate the original Apple Audio Units. Canvas video effects approximate Core Image effects. AV Air’s unavailable system-DLS bass35 uses archived bass38. Sunshine uses the recovered HipHopBank filename. The source resonance setter anomaly is corrected. Source timing and Scheme rounding are not bit-exact.

Recordings stay in this browser’s local storage until explicitly exported. They have no automatic deletion quota. The generated-note trace records sample triggers and requested durations; it is not a measurement of every audible release or hardware delay. Decisions and reasons remain separate reflective entries. Interaction counts do not establish engagement or learning.

Earlier manual WebRTC pairing and same-browser rooms replace the old network service. Camera, microphone and MIDI depend on browser support and permissions. Cross-device timing, hardware behavior and native audio/visual equivalence remain unverified.

Current validation limits

Sixteen automated checks and full decoding of the historical movie pass. A prior browser checkpoint saved and displayed the 597-note synthetic AV take. The continuation could not reopen the prior browser session or run further live browser checks because its local preview process was unavailable and server execution had been denied. No deployment was performed.
