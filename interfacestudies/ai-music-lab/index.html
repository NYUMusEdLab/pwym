What is real, what is new, and what is not built yet?

Continuator runs François Pachet’s official updated Python engine via Pyodide. MusicRNN runs the existing Magenta basic_rnn model. The inversion rule and postprocessing are our authored musical decisions. This teaching interface is new; it is not the historical Continuator or an exact copy of aQWERTYon’s response logic.

MusicRNN receives 4-step-per-quarter quantized notes at 120 BPM. This prototype does not copy aQWERTYon’s octave normalization, scale shaping, or inversion-mode labeling. Its generated pitches/timing remain raw until the explicit filters above. Continuator timing is passed through the existing bridge at two beats per second.

Future modules: performance capture via Scale Rows; raw traces inside the existing aQWERTYon engine; corpus queries; audio/timbre transfer and prompt-to-audio trials. None are simulated here.

Privacy: no application logging

This standalone app has no analytics, accounts, telemetry, session recorder, server-side inference, cookies, or automatic research logging. Notes, examples, generated results, and journal text remain in this browser's memory. Export saves a file only when you request it. Reload clears the app's session data.

The hosting provider may retain ordinary web access logs, such as IP address and requested resource; we cannot promise zero hosting logs. Continuator downloads Pyodide and NumPy from jsDelivr on first use, so that CDN receives normal resource requests. Musical notes and journal text are not sent to it. Magenta's runtime and model are served from this site. Browser caches may retain these public files, not your musical session. Following an external source link is subject to that site's privacy practices.
