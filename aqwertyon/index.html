aQWERTYon maps scales and chords across a QWERTY keyboard, with built-in sounds and visual feedback. Use it for improvisation, classroom music-making and exploring musical relationships.

Web MIDI Integration

aQWERTYon supports Web MIDI API in Chrome-based browsers, allowing you to send MIDI output to other software instruments, digital audio workstations (DAWs), and web-based synths.

This means you can use your QWERTY keyboard to control GarageBand, Logic, Ableton Live, or online synths like Audiotool or Sampulator.
